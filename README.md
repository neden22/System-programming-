# ORBIT · Ethereum Mini App

Космічний інтерфейс для моніторингу Ethereum-гаманців. React + JavaScript + Node.js. Перший робочий етап курсового проєкту з системного програмування.

## Що працює

- Адаптивний інтерфейс: огляд, активність, аналітика, гаманці та налаштування.
- Демопортфель ETH / USDC / LINK, інтерактивні графіки, деталі операцій.
- Пошук, фільтрація, сортування, нотатки, CSV-експорт.
- Збереження до 20 публічних адрес, перевірка формату та повторів.
- Серверний запит реального балансу **нативного ETH** через PublicNode.
- Локальне збереження адрес, нотаток, валюти та режиму приховування сум.
- Telegram SDK: ready(), expand(), кольори оболонки; у звичайному браузері працює автономно.

**Демопортфель, історія, курси й графіки є ілюстративними.** Реальні адреси мають окремий екран балансу; токени та історія реальної адреси ще не завантажуються. Невдалий RPC-запит показує помилку, а не нульовий або вигаданий баланс. Інтерфейс не підписує транзакції та не переміщує кошти.

## Запуск у VS Code / Windows

Встанови Node.js 22.13+ або новішу сумісну версію. Відкрий папку проєкту у VS Code й виконай у терміналі:

```sh
npm install
npm run dev
```

Відкрий http://127.0.0.1:5173. Сервер Node.js одночасно обробляє API та підключає Vite для інтерфейсу. Окремі термінали для клієнта й сервера не потрібні.

```sh
npm test
npm run build
npm start
```

`npm start` обслуговує зібраний `dist/` та `/api/balance` на тому самому порту. `PORT` і `HOST` можна задавати через змінні середовища. Порт за замовчуванням — 5173, адреса — 127.0.0.1. Для зовнішнього хостингу зазвичай потрібен `HOST=0.0.0.0` та HTTPS-проксі.

## Структура

- `src/orbit-app.jsx` — React-інтерфейс, форми, локальний стан, Telegram SDK.
- `src/globals.css` — адаптивна космічна дизайн-система.
- `lib/orbit/data.mjs` — явно позначені демодані.
- `lib/orbit/core.mjs` — LRU-кеш, черга, BigInt-конвертація, фільтрація, CSV.
- `server/balance.mjs` — read-only JSON-RPC адаптер Ethereum.
- `server/index.mjs` — HTTP-сервер Node.js і віддавання застосунку.
- `tests/` — тести алгоритмів і API з контрольованими відповідями провайдера.
- `docs/ARCHITECTURE.md` — системна частина курсової.
- `docs/TELEGRAM.md` — підключення Mini App до власного бота.

## Дані та обмеження

API використовує `https://ethereum-rpc.publicnode.com` і метод `eth_getBalance` з тегом `latest`. Інтернет потрібен для реального балансу. Публічна адреса передається провайдеру. Немає приватних ключів, бот-токенів чи секретів у клієнтському коді. Валідація адреси перевіряє формат, але не EIP-55 checksum. ENS не підтримується.

Кеш має TTL 30 секунд і місткість 100 записів; черга допускає 3 паралельні RPC-запити та 24 очікувані. Тайм-аут — 10 секунд. Вони працюють у пам'яті одного процесу, а не як глобальний розподілений ліміт. Перед масштабним публічним запуском потрібні обмеження запитів на рівні хостингу.

Адреси й нотатки зберігаються у localStorage цього браузера, не синхронізуються між пристроями та можуть бути видалені разом із даними сайту. Валюта UAH у деморежимі використовує фіксований умовний курс 41,50 ₴/$. Google Fonts і Telegram SDK — зовнішні ресурси; без шрифтів є системний fallback.

Перевірки першої версії: 8 автоматичних тестів, валідація форми, фільтри, відновлення локальних даних, десктопний і мобільний вигляд 390 px. У локальному середовищі перевірки живий RPC не відповів; позитивний шлях API перевірено тестовими відповідями. Доступність провайдера потрібно перевіряти у власному середовищі розгортання.

## Наступні етапи

1. Підключити власного Telegram-бота до HTTPS-адреси застосунку.
2. Додати провайдера історії транзакцій і актуальних цін.
3. Додати SQLite та індексатор із відновленням синхронізації для повної системної частини курсової.
4. Розділити великий React-компонент на окремі екрани в міру розвитку проєкту.

Довідка: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Ethereum JSON-RPC](https://ethereum.org/en/developers/docs/apis/json-rpc/), [PublicNode](https://ethereum.publicnode.com/).
